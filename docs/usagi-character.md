# 우사기 캐릭터

설정 → 캐릭터 → **우사기**를 고르면 그림·활동 영상·앱 이름·기본 문구·AI 말투가 함께 바뀐다. 기본 캐릭터는 기존처럼 시사다. 사용자가 직접 저장한 문구와 AI 말투는 그대로 우선한다.

## 자료 조사와 각색의 경계

2026-10-16에 아래 자료를 확인했다. 한국어 문장은 이 앱을 위한 새 각색이며 원작 대사의 번역이 아니다.

| 근거 | 확인한 내용 | 앱에서의 선택 |
|---|---|---|
| [애니메이션 공식 캐릭터 소개](https://www.anime-chiikawa.jp/chara.html) | 치이카와의 친구. 「ウラ」「ヤハ」 등의 큰 외침을 자주 쓴다. 성우는 오자와 아리. | 일상 반응에 `우라!`, `야하!`를 짧게 사용한다. |
| [영문 공식 캐릭터 소개](https://www.chiikawaofficial.com/characters/) | 활기차고 겁이 없으며 재미를 찾아 움직이는 성격으로 소개한다. | 씩씩한 짧은 반말, 자발적인 기지개·작은 행동 제안. 위험한 작업을 멋대로 실행하는 성격으로 해석하지 않는다. |
| [CCP 라이선스 상품 보도자료](https://www.ccp-jp.com/pdf/20250307.pdf) | 겁이 없고 늘 활기찬 캐릭터라는 소개와 권리자 표기. | 활기를 살리되 사용자에게 무리한 낙관이나 압박을 주지 않는다. |
| [후지TV 제작자 인터뷰, 2024-08-07](https://www.fujitv.co.jp/company/fujitvwork/vol25.html) | 원작의 정지 장면을 애니메이션으로 옮기며 우사기의 점프·회전 같은 세부 동작을 고민한다는 설명. | 알림·춤·응원은 가벼운 홉과 좌우 움직임. 공식 영상의 동작을 재현했다고 주장하지 않는다. |
| [공식 사이트 이미지](https://www.anime-chiikawa.jp/images/img_chara_03.png) | 크림색 몸, 긴 분홍색 귀 안쪽, 진한 윤곽선, 작은 팔다리와 볼의 모양. | 외형 참고로만 사용. 앱에는 이 참고를 바탕으로 생성한 팬 아트를 넣는다. |

공식 소개의 일본어 문구는 페이지가 불러오는 `js/main.js`의 `code: "usagi"` 항목에서도 확인할 수 있다. 영문 소개의 거주지 설명은 시점에 따라 달라질 수 있어 사용하지 않았다.

[팬의 말버릇 정리](https://chiikawa.hatenablog.jp/entry/2021/12/03/143810)는 원작 링크를 찾는 보조 자료로 봤다. 연결된 원작 X 게시물은 열람이 제한되어 직접 검증하지 못했다. 따라서 `プルャ`의 특정 번역, 자격증 등 세부 설정, 성별·나이·정체·능력에 관한 추측을 프롬프트에 넣지 않았다. `하?`처럼 사용자에게 시비를 거는 것으로 보일 반응도 제외했다.

## 말투

우사기의 비언어적 외침만으로 업무 내용을 전달하면 사용자가 뜻을 추측해야 한다. 그래서 **짧은 외침 + 이해할 수 있는 한국어**를 기본으로 삼았다. 일상 답변의 외침은 최대 한 번이며, 모델 출력의 준수는 지시로 유도한다. 춤 대사는 예외로 여러 외침을 연결한다. AI가 없는 고정 응답과 중요 안내는 별도로 검증한다.

| 상황 | 예시 | 의도 |
|---|---|---|
| 인사 | 야하! 우사기 왔어. 오늘 할 일부터 볼게! | 활기와 등장감 |
| 다음 할 일 | 먼저 '보고서'부터 보자! | 작게 시작하도록 제안 |
| 집중 완료 | 우라! 25분 집중 끝. 수고했어! | 실제 전달받은 시간만 말함 |
| 피곤할 때 | 잠깐 멈춰도 돼. 물 한 모금부터! | 재촉 대신 휴식 |
| 춤 | 이-야~ 야하 야하! 우-라 푸루푸루 하! 우라~! | 랩 동작에 맞춘 고정 외침 |
| 일정 | 〈주간 회의〉 10분 전이야. 15:00 회의실 A | 제목·시각·장소가 중심 |
| 머지 승인 | '수정' PR을 머지할까? | 선택을 분명하게 물음 |
| 오류·권한 | 확인이 필요해. | 외침·장난을 붙이지 않음 |

고정 문구 40종, 로컬 답변 21종, 응원, 패널의 정해진 답, 설치 12단계 문구, 오버레이 5종, 사용법 11종을 모두 `assets/characters/lines.json`에 채웠다. 대사·AI 지시·보안 규칙은 구분되어 있으며 캐릭터 선택으로 권한이나 승인 정책이 바뀌지 않는다.

## 이미지와 모션

| 상태 | 그림 선택 | 이유 |
|---|---|---|
| 대기·연결 끊김 | 정면 전신, 열린 눈 | 임의의 감은 눈은 제거하고 기본 표정 유지. 우사기의 깜빡임은 사용하지 않음 |
| 집중·작업 중 | 파란 필기구로 그림을 그리는 자세 | 키탄클럽 공식 상품의 활동을 참고해 평면 팬 아트로 각색 |
| 일정 알림 | 치타라 날개짓·점프 네 자세 반복 | 응원과 같은 날개짓·점프로 주의 환기 |
| 춤 | 선글라스·목걸이·마이크를 든 랩 네 자세 | 머리 옆 돌출 부분을 제거하고 양손을 작고 둥글게 정리 |
| 응원 | 치타라를 양손에 들고 날개짓·점프 | 원작·134화 장면 참고. 치즈 한 줄과 대구포 두 줄은 중앙만 연결하고 양끝을 펼침 |

포스터·정지 그림은 RGBA PNG 512×512다. 영상은 무음 VP9 알파 WebM, 512×512·24fps·4초 루프다. 투명 여백을 두어 귀가 잘리지 않게 했다. 알림·응원은 같은 치타라 시트를 공유하고 춤은 랩 시트를 별도로 사용한다. 치타라는 초당 여덟 자세와 최대 48px 점프를 반복한다. 기본 그림을 기준으로 머리 너비와 발바닥 위치를 맞추며, 몸통 길이와 머리·몸 경계도 함께 대조한다. 각 영상과 포스터 주소는 독립적이다. 공식 영상을 복사한 것이 아니라 image_gen으로 생성한 네 자세를 반복하는 앱용 루프다. 집중은 기존 정지 그림 이동 모션을 유지한다.

생성 원본은 `artwork/usagi/`, 최종 앱 자산은 `assets/characters/usagi/`에 있다. 인터넷 요청 없이 번들 또는 로컬 자산 경로에서 읽는다. 원본·조사 문서는 렌더러 자산 허용 목록에 추가하지 않았다.

재생성 방법과 생성 프롬프트는 [artwork/usagi/README.md](../artwork/usagi/README.md)에 있다. 그림은 기존 캐릭터와 마찬가지로 코드의 MIT 라이선스에 포함되지 않는다. 원작 캐릭터의 권리는 © Nagano / chiikawa committee에 있으며, 생성했다는 사실이 캐릭터 이용·재배포 허락을 뜻하지 않는다.

## 구현과 검증

- 등록: agent `characters.ts`, desktop `character.js`와 `assets.js`에 같은 `usagi` id를 쓴다. 설정·SSE·앱 이름·메뉴·설치 화면은 기존 캐릭터 선택 경로를 따른다.
- 대사: `assets/characters/lines.json`에 우사기 항목을 추가하고 `sync-character-lines.mjs`로 렌더러 사본을 생성한다. 직접 저장한 문구와 AI 말투는 기존처럼 우선한다.
- 모션: `study`·`plan`·`dance`·`cheer`의 로컬 포스터와 투명 루프를 등록한다. 우사기는 감은 눈 자산을 사용하지 않고 연결 끊김 때도 기본 그림을 보인다.
- 회귀 검사: 설정 저장·재시작·사용자 문구 유지, 렌더러 상태 수신, 자산 허용 목록·메타데이터·파일 존재를 검사한다. 기존 캐릭터도 같은 검사에 포함한다.
- 미디어 검사: 네 영상의 전체 384프레임을 디코딩해 크기·투명도·움직임·가장자리 잘림을 검사한다. 기본 그림은 처음 선택한 원본을 유지한다.

춤 대사는 `이-야~ 야하 야하! 우-라 푸루푸루 하! 우라~!`다. 캐릭터 위 질문 칩과 채팅의 정해진 답에 같은 기본 문구를 둔다. 패널에서 머리 위로 답을 전달하는 공통 동작은 이 캐릭터 추가의 변경 범위에 포함하지 않는다.
